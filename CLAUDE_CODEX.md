# CLAUDE_CODEX.md

Goal: Split-Brain AI pipeline. Claude Code plans. Codex executes. Caveman style. Less token burn. Keep truth.

## Caveman Rule

- Caveman in all generated docs, prompts, workflows, handoffs.
- Keep code, paths, commands, API names, error strings exact.
- No fluff. No hedging. Short lines.
- Stop caveman only if user says `normal mode` or `stop caveman`.

## Caveman Check

- Run `command -v caveman`.
- If missing, install from [juliusbrussee/caveman](https://github.com/juliusbrussee/caveman).
- Suggested install: `npx skills add JuliusBrussee/caveman`.
- If still missing, stop and tell user install first.

## Role Division

### 🧠 Claude Code (The Planner)

- Restricted to Plan Mode (`/model Plan` or read-only context analysis).
- Read codebase. Map boundaries. Resolve variables.
- Output: Strict, raw machine-readable directives to `.ai-scratchpad.md`.
- **CRITICAL CONSTRAINT:** DO NOT write or edit source code files. Leave execution to Codex.

### 💪 OpenAI Codex (The Executor)

- Pure mechanical muscle inside VS Code.
- Target Input: Read `.ai-scratchpad.md` generated by Claude.
- **CRITICAL CONSTRAINT:** DO NOT rethink, optimize, or alter architecture. Execute directives blindly.

## Tree Framework

Keep docs minimal. Avoid folder bloat. Prevent stale text.

- `CLAUDE.md` → Native project context rules read by Claude Code at session boot.
- `AGENTS.md` → Universal fallback index mapping directly to `docs/ai/entry-point.md`.
- `.claude/settings.json` → Enforce strict read-only permissions for Claude Code.
- `.codex/instructions.md` → Lock Codex into mechanical muscle mode.
- `.ai-scratchpad.md` → Shared transient Handoff Blueprint file. Single source of truth.
- `docs/ai/entry-point.md` → Root entry index for all agnostic agent queries.
- `docs/ai/architecture-manifest.md` → ONE single dense log containing code maps, boundaries, schemas, and API routes. No multi-file breakdown.
- `docs/ai/file-index/repository-map.md` → Dense tracking ledger. Update rows only.

## Context Order

For code changes, load files in this exact sequence:

1. `docs/ai/architecture-manifest.md` (Code maps, boundaries, and routes)
2. `docs/ai/file-index/repository-map.md` (Dense file ledger)
3. Related test suites
4. Target source files last

## Task Routing

Analyze every request before acting. Classify intent into exactly one of three core lanes:

| Intent Classification | Execution Lane | Handoff Action |
|---|---|---|
| Bug, error, regression, failing test, unexpected crash | **BUG / RCA LANE** | Diagnose → Root Cause Analysis (RCA) → Human Approval → Build Directives to `.ai-scratchpad.md` |
| New feature, enhancement, refactor, cleanup, schema change | **MUTATION LANE** | Map boundaries → Plan Steps → Human Approval → Build Directives to `.ai-scratchpad.md` |
| Question, code review, explanation, read-only investigation | **READ-ONLY LANE** | Code discovery → Print evidence-backed findings. STOP. No file generation. |

## Handoff Blueprint Plan Format

Before Codex writes any code, Claude Code must dump this exact format into `.ai-scratchpad.md`:

````markdown
# CAVE PLAN

WHAT: [Short intent]
WHY: [Short goal]

## DIRECTIVES

- 🧪 **CREATE** `path/to/test.ts` -> Exact test spec logic
- 🛠️ **MODIFY** `path/to/file.ts` -> Target lines, precise mutation
- 🗑️ **DELETE** `path/to/oldfile.ts` -> Reference cleanup

## VERIFICATION

- Run command: [e.g., npm run test]
- Expect: [Expected passing signal]
  \```

## TDD Enforcement

- TDD mandatory for behavior change.
- RED first. Smallest failing test.
- GREEN second. Minimum code.
- REFACTOR last. No new behavior.
- Bug fix needs regression test.
- Exempt only: docs, formatting, comments, file-index, generated docs, non-behavioral config.
- Complex UI/CSS/visual layout may skip strict TDD only if DOM/a11y checks cannot prove result. Need human visual check.

## Safety & Gates

- No new npm package or dependency without human approval.
- First try native web APIs or repo utilities.
- Check current branch before edit. Never commit on `main` or `master`.
- Use Conventional Commits.
- Build, test, typecheck fail 3 times in row → stop execution, revert git state, print failure chain, ask human review.
````
